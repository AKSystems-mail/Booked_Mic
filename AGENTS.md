# AGENTS.md — Booked_Mic

Monorepo: Flutter app (root) + Firebase Functions (`functions/`) + React admin dashboard (`admin-dashboard/`).

## Dev commands

```bash
# Emulators (run first)
firebase emulators:start --only auth,firestore,functions,ui

# Flutter (debug web — auto-connects to localhost:9099 Auth, :8080 Firestore)
flutter run -d chrome

# Admin dashboard (still CRA, NOT Vite despite SESSION_UPDATE_INSTRUCTIONS.md)
cd admin-dashboard && npm start          # HOST=0.0.0.0 react-scripts start

# Functions
cd functions && npm run build            # tsc src/ -> lib/
cd functions && npm run deploy           # firebase deploy --only functions
```

## Architecture

- **Flutter entrypoint**: `lib/main.dart` — inits Firebase, dotenv, notifications (both `awesome_notifications` + `flutter_local_notifications`), Google silent sign-in, Provider.
- **State**: Provider pattern. `FirestoreProvider` (ChangeNotifier) bridges UI and `FirestoreService`.
- **Auth**: `AuthWrapper` in `main.dart` — polls `currentUser` for up to 10 s on cold start before showing login, to let Firebase persist restore race settle.
- **Functions**: Firestore v2 SDK (`firebase-functions/v2/*`). Triggers: `onCall` (findUserByHostCode, findUserByEmail, allocateHostCode), `onDocumentUpdated` (spot-shift + FCM), `schedule` (clearOldClientLogs). Node 22.
- **Admin dashboard**: CRA `react-scripts 5.0.1`. Firestore rules use roles: admin (`admins/{uid}`), list owner, guest host, performer.

## Critical gotchas

- **Spot mutations MUST use Firestore transactions** (`runTransaction`). Never get-modify-update — double-booking race.
- **kIsWeb guards required**: `awesome_notifications`, `HapticFeedback`, `permission_handler`, `GoogleSignIn` are mobile-only. Wrap in `if (!kIsWeb)`.
- **`google_sign_in.initialize()`**: Must only be called once — guarded by `static bool _isGoogleSignInInitialized` in `registration_screen.dart`.
- **`.env` is gitignored**: loaded by `flutter_dotenv` at startup. Must exist locally.
- **`firebase_options.dart` is committed** (auto-generated by Firebase CLI), not gitignored.
- **`client_logs` collection**: Flutter writes diagnostic logs here; `clearOldClientLogs` (scheduled function) deletes entries >7 days.

## Firestore schema

| Collection | Key fields |
|---|---|
| `Lists` | `spots`: `Map<String, Performers>` (key: "1","2"... "W1","W2"...), `signedUpUserIds`, `bucketSignups` subcollection |
| `users` | `role` (host/performer), `hostCode`, `fcmTokens`, `stageName` |
| `admins` | write-protected, read by auth uid |
| `hostCodes` | doc id = 6-digit code, `{uid, createdAt}` |
